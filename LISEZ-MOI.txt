ROADTRIP DIB 2026

Cette version comprend :
- itinéraire complet sur 17 jours ;
- huit hébergements avec adresse, arrivée, départ, accès, parking et navigation ;
- carte et géolocalisation ;
- restaurants et courses autour de soi ;
- météo locale ;
- SOS ;
- emplacement de la voiture ;
- 17 badges ;
- synchronisation familiale prête à configurer avec Firebase.

MISE À JOUR GITHUB
1. Décompresser le ZIP.
2. Dans le dépôt GitHub, remplacer les fichiers existants par tout le contenu de ce dossier.
3. Conserver le dossier icons à la racine.
4. Attendre le nouveau déploiement GitHub Pages.

La synchronisation reste en mode local tant que firebase-config.js n’est pas configuré.
