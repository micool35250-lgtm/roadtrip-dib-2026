ROADTRIP DIB — CONNEXION FAMILIALE

1. Firebase Console > Authentication > Mode de connexion : activer E-mail/Mot de passe.
2. Authentication > Utilisateurs > Ajouter un utilisateur.
3. Utiliser l’identifiant familial défini et le mot de passe choisi.
4. Ne jamais écrire le mot de passe dans les fichiers GitHub.
5. Chaque iPhone saisit les identifiants une seule fois ; Firebase conserve ensuite la session.
6. Pour renforcer Firestore, limiter les règles au UID de ce compte après sa création.
